# The Shooting Star — Unofficial Bedrock Port

An unofficial community recreation project for Minecraft Bedrock Edition, targeting Minecraft Bedrock v26.52 on iPadOS.

## Status

**Prototype / work in progress.** This repository is not affiliated with or endorsed by the original mod author. It does not contain the original Fabric JAR or original mod assets.

The original mod is a Java Edition Fabric mod and cannot run directly on iPad Bedrock. This project recreates selected ideas with Bedrock add-on formats; it is not a conversion of the Java bytecode.

## Planned prototype features

- Stellar Remote-style ability item
- Railgun-inspired ranged attack
- Gungnir-inspired spear attack
- Seven Stars-inspired ability
- Touch-friendly item activation using Bedrock-supported interactions

Feature parity and exact effects are not guaranteed. Compatibility with Bedrock 26.52 must be tested in Minecraft.

## Development

The first milestone is a minimal Behavior Pack with a script-driven ability item. Resource Pack models, textures, sound, and more advanced effects can be added after the basic pack imports and runs.

## Install (once a release is published)

1. Download the .mcaddon release to your iPad.
2. Open the file and choose Minecraft.
3. In Minecraft, enable the pack for a test world.
4. Create a backup before testing in an existing world.

No installable release is published yet.
